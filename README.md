Java 콘솔 프로그램으로 구현한 연습 프로젝트입니다.**

## 🧩 시나리오

달(month)을 입력받아 해당 월이 속한 계절을 출력한다.

---

## 📌 입력 / 출력 정리

### 입력
- `month` : 1~12 사이의 정수

### 출력
- 해당 월이 속한 계절  
  (`봄`, `여름`, `가을`, `겨울`)

### 상태 (계속 들고 있어야 하는 값)
- `month`

---

## 🔎 조건 정리

### 종료 조건
- 계절 출력 후 프로그램 종료

### 분기 조건
- 봄 : 3, 4, 5  
- 여름 : 6, 7, 8  
- 가을 : 9, 10, 11  
- 겨울 : 12, 1, 2  

### 예외 / 에러 조건
- `month < 1 || month > 12`  
  → `"잘못된 입력입니다!"` 출력 후 다시 입력

---

## 🔁 로직 흐름 설계

### 1) 시작 시
- 초기화 작업 없음

### 2) 반복 흐름
1. 월(month)을 입력받는다.
2. 입력값이 1~12 사이인지 검사한다.
   - ✅ 예  
     - `switch` 문 실행  
       - `case 3, 4, 5` → `"봄"` 출력  
       - `case 6, 7, 8` → `"여름"` 출력  
       - `case 9, 10, 11` → `"가을"` 출력  
       - `case 12, 1, 2` → `"겨울"` 출력  
   - ❌ 아니요  
     - `"잘못된 입력입니다!"` 출력  
     - 다시 입력받기
3. 계절 출력 후 프로그램 종료

### 3) 종료
- 프로그램 종료
